# 결정 기록

## 기록·변경 규칙

- 결정 ID는 `DEC-001`처럼 순서대로 부여하고 재사용하지 않는다. 결정일은 동의가 확인된 날짜이며 단순 기록·편집일과 구분한다.
- 상태는 제안·승인·대체됨·철회로 구분한다. 제안은 승인 근거가 확인될 때만 승인으로 바꾸고 동의 근거를 남긴다.
- 변경 시 기존 결정을 지우지 않고 새 DEC ID와 대체 관계를 양쪽에 기록한다. 중요한 결정은 새 ADR로 배경·대안·영향·위험·재검토 조건을 남긴다.
- ADR이 있는 항목은 식별 가능한 요약과 링크만 둔다. ADR이 없는 작은 결정만 결론·핵심 이유를 짧게 기록한다.
- 결정 기록에 현행 정책·상세 계약·최신 테스트 결과를 복사하지 않고 해당 기준 문서([AGENTS](../AGENTS.md#작업-목적에-따라-읽을-문서))로 연결한다.
- ADR 양식: [docs/adr/TEMPLATE.md](adr/TEMPLATE.md). 제안서의 후보·권장·단순 기술 언급을 승인 결정으로 바꾸지 않는다.
