# 설계

상태: 상세 설계와 연동 계약은 미정. 기존 [제안서](../PRD.md)의 확정 방향을 참조하며, 새 설계는 합의 후 이 문서에 기록한다.

## 아키텍처

확정 방향과 핵심 스택은 [원문 1.2·5.0·7.1~7.2절](../PRD.md)을 따른다. 원문에서 확정한 3티어 구성, 2D 물리·3D 렌더링, 온라인 서버 권한을 새 결정으로 재등록하지 않는다.

후보 라이브러리 채택, 물리 엔진, 빌드 구성, 코드 디렉터리와 패키지 경계 세부는 미정이다([원문 5.0·7.4·14.4절](../PRD.md)).

## 주요 처리 흐름

[원문 3.6·7.2~7.3절](../PRD.md)의 증강 사용·시뮬레이션·기록 재생 방향을 참조한다. 상태 전이와 예외·이탈 처리의 상세 합의는 미정이다([원문 14.1~14.2절](../PRD.md)).

## API

요청·응답·오류 형식과 검증 규칙의 연동 계약은 미정이다. [원문 9장](../PRD.md)의 API·이벤트 목록은 기존 제안이며 완결된 계약으로 간주하지 않는다. 합의 절차는 [협업 규칙](CONTRIBUTING.md)을 따른다.

## 데이터 모델

테이블·필드·관계·제약·트랜잭션의 상세 명세는 미정이다. [원문 8장](../PRD.md)은 미확정 모델이며, [원문 14.3절](../PRD.md)의 미완료 항목과 함께 검토한다.

API와 데이터 모델은 우선 이 문서에서 관리한다. 내용이 커지거나 독립 관리가 필요해지면 `API.md`·`DATABASE.md`로 분리하고 이 문서에는 링크만 남긴다.
