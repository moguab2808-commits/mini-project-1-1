# 작업 관리

[GitHub Issues](https://github.com/moguab2808-commits/mini-project-1-1/issues)를 작업 관리의 기준으로 사용한다. 담당자·상태·완료 조건 체크리스트·의존성은 해당 Issue에서만 관리하며 이 문서에 복제하지 않는다.

상위 Issue 링크: 미정(미생성). 상위 Issue가 생기면 여기에 링크만 추가한다.

작업 등록은 [Issue 양식](../.github/ISSUE_TEMPLATE/task.md)을 사용하고, 진행 흐름과 상태 정의는 [협업 규칙](CONTRIBUTING.md)을 따른다.
