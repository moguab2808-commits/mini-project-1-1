# 에셋 출처·이용 조건 기록

AI·생성 도구·외부 출처를 쓴 에셋의 출처와 이용 조건을 기록한다. 직접 제작한 에셋(코드 도형·SVG)은 적지 않는다. 조달 방식과 용량 한도는 [TECH_STACK](design/TECH_STACK.md#에셋-조달-계획)을 따른다.

에셋을 저장소에 넣는 PR에서 같은 변경으로 한 줄을 추가한다. 이용 조건을 확인하지 못했으면 "미확인"으로 적고 반입하지 않는다.
