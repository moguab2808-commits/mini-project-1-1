### 후속 사용자 규칙 정정 (DEC-014)

- 각자 방해요소 1개 보유, 1·3·5·7·9라운드 교체, 다음 교체까지 제한 내 반복 사용을 PRD·결정 기록·GAME/API 초안에 반영했다.
- 기존 설계는 알 이동 중 새 사용을 거부한다. 허용 여부를 사용자에게 확인 중이며 기록 후 재생을 실시간 계산 방식으로 바꾸는 승인은 아직 기록하지 않았다. 교체 시 제한·효과 승계도 미정으로 남겼다.

### 상시 사용 명시와 실시간 설계 초안

- 사용자가 내 턴·상대 턴·조준 여부와 관계없이 언제든 사용하도록 명시했다. 직전 이동 중 사용 논의와 함께 DEC-015에 기록하고 PRD·GAME·API·LOCAL의 사용 제한을 수정했다.
- 기록 후 재생으로는 이동 중 새 입력을 처리할 수 없어 aiming/moving 상태와 별도 effects 구조로 초안을 교체했다. 실시간 고정 틱·스냅샷·보간을 ADR-0004/DEC-016 제안으로 기록했다. 아키텍처 대체 승인이나 성능 통과로 표시하지 않았다.
- 게임 판정·기절 대상·랜덤형 자동 발동·교체 시 제한 승계는 합의 전이다. 기존 기록은 당일 작업 이력이며 현행 초안은 GAME을 따른다.
- 후속 검증: 변경한 12개 문서의 상대 링크·앵커 346개 검사 오류 0개, `git diff --check` 통과. 실행 검증은 구현이 없어 미수행.

### 사용자 결정 반영 (DEC-016·017)

- 사용자 발화로 개발자 B도 실시간 계산에 합의했음을 확인했다. DEC-016·ADR-0004를 승인으로 바꾸고 DEC-013/ADR-0003의 기록 후 재생 부분의 대체 관계를 연결했다. B의 API-001 상세 이벤트 검토는 아직 수행하지 않았다.
- 랜덤형 턴 무관 상대 자동 발동, 기절의 상대 대상, 교체 시 보유·지속 효과·게이지·쿨타임 초기화, 방해요소 판 돌리기의 상대 턴 허용, 판 돌리기·책상 흔들기 자체로 알이 떨어지지 않는 규칙을 DEC-017과 PRD·GAME에 반영했다.
- 검증 대상은 문서 링크·중복 충돌·diff 형식이다. 구현·실시간 성능은 미검증이다.
- 후속 문서 검증: 변경한 12개 문서에서 상대 링크·앵커 351개 검사 오류 0개, `git diff --check` 통과. 게임 동작·실시간 지연은 구현이 없어 미검증.

### 후속 효과 규칙 (DEC-018)

- 랜덤형의 15초 구간·약 1초 발동 초기 기준, 바람의 상대 조준 방향 자동 이동, 책상 흔들기 중 알 조작 허용을 PRD·GAME·결정 기록에 반영했다.

### 판 회전·벽 배치·판 이탈 (DEC-019)

- 사용자 답변에 따라 판과 함께 알·설치물·진행 방향을 회전시키고, 벽은 격자 빈 후보만 허용하며 미리보기를 초록/빨강으로 표시하도록 PRD·GAME에 반영했다. 판 이탈은 game-core 물리에서 판 모양별로 판정하도록 상세화했다.
