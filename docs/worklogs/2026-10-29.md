### 수행과 관찰

- PRD: 회원등록에서 아이디를 제거하고 닉네임을 로그인 식별자로 바꿨다. 메인메뉴·방 참여를 로비로 통합했고 캐릭터 변경 절을 추가했다. 게임 화면은 가운데 판과 투명 프로필 배치, 재도전하기·나가기로 바꿨다. 확정되지 않은 세부는 미정으로 표시했다.
- DECISIONS에 DEC-006을 추가했다. TASKS에 UI-001을 등록했고 PROGRESS를 요약 갱신했다. DATABASE 미정 항목의 식별자 표현도 맞췄다.
- 시안은 Artifact 게시 응답에서 다섯 번 모두 성공을 확인했다(canvas.json, Main, Avatar, Lobby, Game). 렌더링 결과를 화면으로 직접 확인하지는 않았다.
- 문서 링크·앵커는 [2026-10-28 worklog](2026-10-28.md#doc-001-문서-책임과-구조-재편)의 검사 스크립트를 저장소 루트에서 실행해 확인했다. 내부 링크 219개에서 누락이 없었다. `git diff --check`도 통과했다.

- 3D 인게임 시안: `알까기 바 (2).html` 사본에 투명 프로필 배치(왼쪽 위 상대, 오른쪽 아래 나)와 결과 창의 재도전하기·나가기만 바꿔 <https://claude.ai/artifact/R7tW789HkwcAPn9oYZvGc8>에 게시했다. AI 대전과 난이도 선택은 그대로 두었다. 원본 파일은 수정하지 않았다. 스크립트는 Node `new Function` 구문 검사를 통과했다.

### 한계·미검증

- 3D 시안의 나가기는 로비가 없어 시작 화면으로 돌아간다. 프로필 그림은 3D 캐릭터의 피부·머리색을 따른 2D 얼굴이고, 레이팅 변화는 표본 값이다. 브라우저에서 직접 실행해 보지는 않았다.

- 시안의 레이팅·전적·닉네임은 표본 값이고 배치 수치는 요구사항이 아니다. 턴·시간·라운드 표시와 기권 버튼의 위치는 미정 항목을 보여주기 위한 임시 배치다.
- 시안에서 즉시 참가·만들기·코드 입장은 모두 인게임 화면으로 이동한다. 대기실 화면은 시안에 없다.
- 캐릭터 변경은 같은 아트보드 안에서만 반영되고 인게임 아트보드로 이어지지 않는다. 인게임 캐릭터는 Tweaks 값으로 바꾼다.
- 시안을 브라우저에서 직접 렌더링해 확인하지 않았다.

### 문서 대조·후속 작업

- 사용자 검토 후 화면 미정 항목([화면 미정 사항](../PRD.md#화면-미정-사항))을 정하고 UI-001 수용 기준을 갱신한다.
- 상세 프로필·랭킹·건의·환경설정의 진입 위치가 정해지면 로비 시안에 추가한다.

## DOC-004 개발 전 문서 충돌 정리

### 범위와 기준 문서

- 작업: [DOC-004](../TASKS.md#doc-004-개발-전-문서-충돌-정리), 결정: [DEC-007·DEC-008](../DECISIONS.md#결정-색인)
- 비교 기준: 같은 날 개발 전 검토에서 정리한 충돌 C1~C10·규칙 불일치 R1~R5와 사용자의 항목별 결정, UI-001 디자인 캔버스의 인게임 아트보드(`project/Game.dc.html`)

### 작업·검증 조건

- 브랜치 `test`, HEAD `0ffe7d4`, UI-001의 미커밋 변경을 포함한 작업 파일을 대상으로 했다. 로컬 Python 3의 임시 스크립트(저장소 미포함)로 코드 블록 밖 상대 Markdown 링크의 대상 파일과 제목 앵커를 검사했다.

### 수행과 관찰

- PRD: AI 봇 대전을 목표·MVP 범위로 옮겼다. 게임 화면을 3D로 확정하고, 디자인 캔버스 기준 배치(상단 가운데 턴·시간·라운드, 프로필 아래 남은 알, 왼쪽 하단 기권, 글자 그림자)를 반영했다. 그 밖에 닉네임 변경 불가, 레이팅 정수 반올림, 도달 시각 없는 랭킹 정렬, 로그인 연속 5회 실패 제한을 반영했다. "서버는 제거됨만 기록"은 판정 위치 미정 문장으로 바꿨다. R1~R4는 DEC-008의 임시 기준으로 한 곳에 통일했다.
- 설계 후보: DATABASE에서 `login_id`를 제거하고 `character_id`를 추가했다. API에서 닉네임 변경을 제거하고 캐릭터 변경·`room:quickJoin`·`rematch:*`를 추가했다. AUTH에 로그인 시도 제한 절을 추가했다. LOCAL 다이어그램의 정보 패널을 캔버스 배치로 바꿨고, GAME·TECH_STACK에 3D 확정을 반영했다.
- PROGRESS 확인일을 2026-10-29로 갱신했다. 기준 화면 프로토타입 `알까기 바 (2).html`을 커밋 대상에 포함했다.
- 검사 결과: 상대 링크·앵커 257개 검사 통과(이 절 추가 후 재검사). `git diff --check` 통과.

### 한계·미검증

- 디자인 캔버스에는 증강 영역이 없어 증강 영역 배치는 미정으로 남겼다. 캐릭터 종류(캔버스의 동물 6종)는 결정 범위가 아니어서 확정하지 않았다.
- DEC-008의 규칙은 사용자가 다시 정할 임시 기준이다. AI 대전의 진입·난이도·전적 반영, 로그인 제한 시간·집계 단위는 미정이다.
- 리뷰·기준 브랜치 병합은 수행하지 않았다.
