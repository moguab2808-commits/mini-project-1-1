## IMPL-026 방해요소 화풍

### 범위와 기준 문서

- 작업: [IMPL-026](../TASKS.md#impl-026-방해요소-화풍)
- DEC ID: [DEC-080](../DECISIONS.md#결정-색인)(6종), [DEC-081](../DECISIONS.md#결정-색인)(나머지·HUD 아이콘·진한 색과 광택)
- 비교 기준: 로그인 일러스트의 폭탄·블랙홀·슬라임·벽돌 벽·물총 빛줄기

### 작업·검증 조건

- 브랜치·커밋: `main`(`6291a1b`) 위 미커밋 변경(IMPL-025 변경 포함)
- 환경: IMPL-025 절과 같다(SwiftShader 소프트웨어 렌더링, 장면 하네스 `zones=1&walls=1&sticky=1`, `beam=water_gun`, `beamby=0`). 가까운 모습은 2560×1440으로 그려 판 부분만 잘라 봤다.

### 수행과 관찰

- 폭탄: 몸체를 납작한 공에서 해골 무늬 검은 공(반지름 `mineRadius` 그대로)으로 바꾸고 쇠 마개·심지·불꽃(깜빡임과 튀는 불티)을 더했다. 붉은 깜빡이 불빛은 불꽃이 대신한다.
- 자석: 붉은 원 대신 보라 소용돌이 원판(반지름 `magnetRadius`)·빠르게 도는 빛 팔·검은 핵과 빛 고리·나선으로 빨려 드는 빛 알갱이 16개. 처음에는 꿀색 판 위에서 희뿌옇게 보여 색을 짙게 하고 빛 팔을 약하게 했다.
- 구멍: 검은 원 대신 천천히 도는 별빛 우물 + 들쭉날쭉한 나무 테(구멍 바깥, 판정 원은 그대로) + 가장자리 보랏빛 맥동.
- 끈끈이: 원기둥 대신 가장자리가 울퉁불퉁한 낮은 돔(판정 지름의 0.92~1.0배)과 가장자리·바깥 방울, 부풀었다 터지는 거품 6개.
- 벽: 회색 벽돌을 주황 장난감 벽돌로 바꾸고 노란 윗면에 돌기 6개를 더했다. 처음에는 옆면이 어두운 적갈색으로 보여 밝은 색과 약한 자체 발광을 줬다. 가짜벽·이동 장애물도 같은 모양이다(가짜벽은 진짜와 같아야 한다).
- 물총: 파란 물방울을 더 짙고 빛나게 하고, 가운데 빛 줄기 두 겹·반짝이 40개·파란 조명을 더했다. 손에 든 물총은 둥근 파란 몸체·노란 총구·주황 펌프·빛나는 물통이다. 맞은 자리에 물보라 구를 두었더니 맞는 쪽 카메라 바로 앞이라 화면 가운데가 하얗게 덮여 뺐다.
- 원자료: [artifacts/2026-11-05-impl-026](artifacts/2026-11-05-impl-026/)(`before-*`·`after-*`; `before-water-gun.jpg`는 IMPL-025 이전 바 테마 화면이다)
- 명령: `npm test`(33개 파일, 394개 통과), `npm run lint`, `npm run format`, `npm run build -w @alkkagi/client` 통과

### 한계·미검증

- GPU 프레임 시간은 재지 않았다. 자석 하나에 메시가 약 20개, 폭탄 하나에 약 10개로 늘었다.
- 폭탄이 이전(납작한 공)보다 높아져(심지 포함 약 3cm) 멀리 있는 알을 조금 가릴 수 있다. 실제 경기에서 확인이 필요하다.
- 실제 AI·로컬 2인 경기와 사용자 확인은 아직이다. 배치 미리보기·HUD 아이콘은 바꾸지 않았다.

### 2차: 나머지 방해요소·HUD 아이콘, 진한 색과 광택(DEC-081)

- 조건은 1차와 같다. HUD 아이콘은 개발 서버에 임시 페이지(아이콘 20개 격자, 72px)를 띄워 변경 전(`HEAD` 파일)과 뒤를 같은 조건으로 찍고 임시 파일은 지웠다.
- 바꾼 것: 중력 구역(짙은 파랑 바닥 텍스처·빛 테·금빛 모서리·숨쉬는 큰 화살표), 미끄럼 장판(눈송이·금 간 결 텍스처, 클리어코트 광택, 자체 발광 0.45), 방향 반전(분홍·보라 마법진이 회전, 바깥 고리 맥동), 분신술 허상(보랏빛 반투명 알·퍼지는 빛 고리·도는 반짝이 4개), 이동 장애물 경로(금빛 레일·주황 줄무늬), 후레쉬(금빛 원뿔·반짝이 40개, 빨간 몸체·금빛 머리 손전등), 기절 별(입체 금빛 별, 광택·자체 발광). 앞 6종은 슬라임·벽돌·벽돌 윗면·폭탄·구멍 테에 클리어코트를 넣고 색을 진하게 했다. HUD 아이콘 20개를 다시 그렸다.
- 관찰: 더하기 빛(additive)으로 그린 방향 반전·분신술 고리는 꿀색 판 위에서 거의 흰색으로 바래 덮는 반투명으로 바꿨다. 얼음판은 따뜻한 조명 아래 회청색으로 보여 텍스처 자체 발광을 넣었다. 밤 옥상 테마에서도 같은 모양으로 보인다.
- 원자료: [artifacts/2026-11-05-impl-026](artifacts/2026-11-05-impl-026/)의 `after2-*`, `before-hud-icons.jpg`
- 명령: `npm test`(33개 파일, 394개 통과), `npm run lint`, `npm run format`, `npm run build -w @alkkagi/client` 통과
- 한계: 후레쉬는 맞는 쪽 화면 가운데를 금빛으로 밝게 덮는다(변경 전에도 흰빛으로 덮는 의도된 방해다). 실제 경기 HUD 안의 아이콘 모습과 GPU 프레임 시간은 확인하지 못했다. `MeshPhysicalMaterial`(클리어코트)이 늘어 저사양 기기에서 비용이 조금 늘 수 있다.

## IMPL-027 자석 궤도 정지

### 범위와 기준 문서

- 작업: [IMPL-027](../TASKS.md#impl-027-자석-궤도-정지), [DEC-082](../DECISIONS.md#결정-색인)
- 비교 기준: [GAME 자석](../design/GAME.md), PRD 추가 방해요소의 자석 행

### 작업·검증 조건

- 브랜치·커밋: `main`(`6291a1b`) 위 미커밋 변경(IMPL-025·025 변경 포함)
- 환경: WSL2 Linux, Node 24.22.0, vitest(`npm test`)

### 수행과 관찰

- 사용자 질문(멈춰 있는 알도 끌려가는가)을 먼저 `game-core`로 재현했다: 범위 안에 멈춰 둔 알은 먼 곳 발사·자석으로 들어가는 발사 모두에서 제자리였다. 0.11cm/s 이상이면 움직이는 알로 보고 곧장 강하게 빨려 들어, 살짝 건드려진 알이 멈춰 있다가 끌려가는 것처럼 보일 수 있다고 설명했고 사용자는 문제없다고 했다(임시 테스트 파일은 지웠다).
- 변경: 자석 범위에 닿은 움직이는·떠 있는 알에 `orbit`을 달아 속도를 버리고, 2초 동안 초당 1.25바퀴·반지름이 부드럽게 0으로 줄어드는 나선을 돌린다(떠 있던 높이는 0.4초에 내려온다). 도는 알은 다른 힘·벽·알 충돌·폭탄·반전·구멍 판정에서 빠지고 `allSlow`가 거짓이라 턴이 끝나지 않는다. 다 돌면 중심, 차 있으면 알 지름 간격 육각 고리의 가장 가까운 빈자리(벽·구멍·판 밖 제외)에 멈춘다. 시간 상한(10초)이면 그 자리에서 궤도를 끝낸다. `magnetAccel`·`magnetTangentDamping`을 지우고 `magnetOrbitSeconds`·`magnetOrbitTurnsPerSec`를 더했다.
- 테스트: `hazards-extra.test.ts`에 4개 추가(2초 회전·중심 정지·회전량 > 1바퀴, 두 알 중심·옆 정지와 비겹침, 멈춘 알 제외, 첫 번째·두 번째 친 사람별 자석 유지·라운드 교체). 기존 "지나가는 알이 자석 쪽으로 휜다"도 통과한다.
- 명령: `npm test`(33개 파일, 398개 통과), `npm run lint`, `npm run format`, `npm run build` 통과
- 스냅샷은 초당 30번(`SNAPSHOT_HZ`)이라 초당 1.25바퀴면 스냅샷 사이 약 15°씩 돌아 화면 보간으로 이어진다(계산, 화면 미확인).

### 한계·미검증

- 실제 AI·로컬 2인·온라인 화면에서 도는 모습을 보지 않았다.
- 도는 알은 다른 알을 통과해 지나간다(부딪힘 없음). 다 돈 자리 찾기는 다른 알을 밀지 않고, 고리 8겹 안에 빈자리가 없으면 중심에 둔다(실제로는 일어나기 어렵다).

- 구성: `audio/engine.ts`(Web Audio 문맥 하나, 배경음악·배경 소리·효과음 세 갈래 음량과 압축기, 첫 입력 때 열기, 버튼 클릭 소리, 화면별 음악 요청 우선순위 `RequestStack`, `files.ts` 등록 파일 우선 재생), `audio/sfx.ts`(효과음 40종·물줄기 반복), `audio/music.ts`(곡 5개: 조·빠르기·화음·악기가 다른 16마디 결정적 작곡 + 미리 예약하는 재생기), `audio/ambience.ts`(테마 4종), `audio/use-audio.ts`, `game/game-audio.ts`(이벤트 → 효과음, 스냅샷에서 충돌·떨어짐·구멍·떠오름·착지·자석 추정, 남은 5초 째깍). 옛 `game/emote-audio.ts`를 지웠다. 환경설정 음량을 3개로 나누고 효과음은 옛 키(`alkkagi.volume`)를 잇는다.

- AI 경기(`/ai`)를 실제로 시작해 감정표현 2번을 쓰고 30초 진행하는 동안 콘솔 오류가 없었다(기존 three `Clock` 경고 1건만).

### 한계·미검증

- 실제로 들어 본 크기·분위기는 사용자 확인이 필요하다. 감정표현 목소리는 합성 흉내라 녹음 파일로 바꾸는 것이 2·3단계다.
- 충돌 소리는 30Hz 스냅샷에서 거리·상대 속도로 추정해 아주 빠른 스침은 놓치거나 늦을 수 있다. 벽에 튕기는 소리는 없다.
- 온라인 경기(서버 연결)에서는 확인하지 못했다. 같은 세션 이벤트를 쓰므로 같게 동작할 것으로 본다.
- 경기 중에는 환경설정 창이 없어 음량을 바꾸려면 로비로 나가야 한다.
- 켜기 스위치(DEC-085): 음량과 따로 `alkkagi.sound.<갈래>`에 저장하고(기본 켜짐) 엔진은 꺼진 갈래의 음량을 0으로 둔다. 설정 창을 임시 페이지에 띄워(배경음악 꺼짐 상태) 스위치·흐린 음량 막대를 촬영해 확인했고 임시 파일은 지웠다. `app.test.ts`에 저장·기본값 확인을 더했다. `npm test`(409개), lint, format, 빌드 통과.
- 2·3단계(DEC-086): 서브 에이전트가 CC0 후보를 찾아 페이지의 라이선스를 확인했고 사용자가 골랐다. 고른 17개 페이지를 다시 열어 Freesound "Creative Commons 0"(publicdomain/zero/1.0)·OpenGameArt License(s) "CC0"를 확인했다(교실 곡 묶음 readme도 "Creative Commons Zero (CC0)"). Freesound는 공개 HQ 미리듣기 MP3, OpenGameArt는 원본 파일을 저장소 밖 임시 폴더에 받고, 저장소 밖에 설치한 ffmpeg 6.0(static)으로 잘라(소리 구간은 silencedetect로 찾음) 크기를 맞춰(짧은 소리 최대 −2~−4dB, 음악 −18LUFS, 배경 소리 −24~−30LUFS) MP3로 만들었다(효과음 모노 96kbps, 음악 스테레오 64kbps, 배경 소리 30초 모노 48kbps). 합계 약 3.1MB(효과음 약 120KB), 기존 public 약 0.8MB와 합쳐 약 3.9MB.
- 엔진: 효과음 파일은 소리를 열 때 미리 받고, 음악·배경 소리는 요청한 화면에서 받아 같은 곡은 다시 받지 않는다. 녹음 끝·처음이 매끄럽지 않아도 끊기지 않게 2.5~3초 겹쳐 잇는다(`loopBuffer`). 파일별 크기 배율(`fileGain`)로 합성 소리와 크기를 맞췄다. 판 밖으로 떨어지는 소리는 지웠다.
- 확인: 헤드리스 Chromium에서 17개 파일을 모두 디코딩해 배율 적용 뒤 크기를 쟀다(음악 RMS 0.03~0.04로 합성 곡과 비슷, 밤 옥상 배경 소리 0.067·놀람 0.087은 커서, GG 0.013은 작아서 배율을 조정). AI 경기를 시작하면 효과음 파일 8개·로비 곡을 받고 경기 시작 때 바 곡·바 배경 소리만 받는 것(모두 200)과 콘솔 오류가 없는 것을 확인했다. 등록 파일 존재·키·효과음 100KB·합계 한도 테스트를 더했다. `npm test`(35개 파일, 410개 통과), lint, format, 빌드(파일이 `dist/audio/`에 복사됨) 통과.
- 한계: 실제로 들어 보지 않았다(크기 배율은 측정값 기준). 반복 이음매의 자연스러움, 감정표현 길이·분위기는 사용자 청취로 확인이 필요하다.
- 소리 버튼(DEC-087): 로그인 화면은 로비 곡을 요청하고 있었고, 헤드리스 Chromium에서 첫 클릭 전에는 소리 파일을 받지 않다가 클릭 직후 효과음 파일과 `music/lobby.mp3`를 받는 것을 확인했다(브라우저 자동 재생 제한). 소리 설정 칸을 `app/sound-controls.tsx`(+ 자체 완결 CSS)로 떼어 환경설정 창과 함께 쓰고, `app/sound-button.tsx`를 로그인·경기(`GameScreen`)·AI 설정 화면 오른쪽 위에 두었다. 막혀 있으면 "소리 켜기"와 빛남, 열린 뒤는 스피커(모두 끄면 ✕) SVG 아이콘이다(처음 이모지는 글꼴이 없는 브라우저에서 네모로 보여 SVG로 바꿨다). 로그인 잠김·열린 창, AI 경기 중 창을 열고 배경음악을 끈 화면을 촬영했고 바깥을 누르면 창이 닫히는 것, 콘솔 오류가 없는 것을 확인했다. `npm test`(410개), lint, 빌드 통과.
