# API·실시간 통신 계약

## 상태

| 구분 | 상태 |
| --- | --- |
| 승인된 미구현 설계 | 없음 |
| 현재 구현 | 없음 |
| 미정 | 아래 후보 전체. 합의·채택 전 구현 계약으로 사용하지 않는다. |

상위 구조는 [DESIGN](../DESIGN.md), 제품 동작은 [PRD](../PRD.md)를 따른다. 이 문서는 전송 방식·메시지·요청·응답·오류·검증 경계를 관리한다. 선택 이유는 [결정 기록](../DECISIONS.md)에 둔다.

## 기존 후보: 인터페이스

### 후보: REST API

> 아래 API는 재검토할 후보이며 경로·전송 방식·채택 여부 모두 미정이다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/api/auth/signup` | 회원가입 |
| POST | `/api/auth/login` | 로그인 |
| POST | `/api/auth/logout` | 로그아웃 |
| GET | `/api/me` | 내 정보 |
| PATCH | `/api/me/nickname` | 닉네임 변경 |
| PATCH | `/api/me/password` | 비밀번호 변경 |
| GET | `/api/me/matches` | 최근 전적 |
| GET | `/api/ranking` | 랭킹 목록 |
| POST | `/api/suggestions` | 건의 등록 |
| GET | `/health` | 서버 상태 확인 |

### 후보: Socket.IO 이벤트

- 연결 시 세션으로 사용자를 인증하며, 로그인하지 않은 사용자는 연결을 거부한다.
- 같은 계정의 새 연결이 생기면 기존 연결에 `session:replaced`를 보내고 끊는다.

| 방향 | 이벤트 | 설명 |
|---|---|---|
| C → S | `room:create` | 방 생성 |
| C → S | `room:join` | 방 입장 (공개 방은 방 id, 비공개 방은 방 코드) |
| C → S | `room:leave` | 방 나가기 |
| C → S | `room:start` | 게임 시작 (방장만, 상대 입장 시) |
| C → S | `lobby:subscribe` | 공개 방 목록 구독 |
| S → C | `lobby:rooms` | 공개 방 목록 갱신 |
| S → C | `room:state` | 대기실 상태 |
| S → C | `room:closed` | 방장 이탈 등으로 방이 닫힘 |
| S → C | `game:start` | 게임 시작 (판, 알 배치, 선공) |
| S → C | `augment:choices` | 증강 후보 3개 (제한시간 20초 포함) |
| C → S | `augment:pick` | 증강 선택 |
| C → S | `augment:use` | 증강 사용 (증강 id, 적용 방식에 맞는 내 알 id / 전체 범위 / 위치 좌표 / 랜덤 위치 요청 등). 서버 검증 후 사용 확정, 턴 유지 |
| S → C | `game:state` | 증강 사용 등으로 바뀐 게임 상태 (**플레이어별 뷰**) |
| C → S | `shot:submit` | 발사 (알 id, 각도, 세기 0~100). 증강 사용은 `augment:use`로 별도 처리 |
| S → C | `sim:result` | 시뮬레이션 기록과 결과 (**플레이어별로 다른 내용**: 분신 구분 정보, 안개 속 알 제외) |
| S → C | `turn:change` | 턴 변경 (남은 시간 포함). 쌍발이면 같은 플레이어의 추가 발사 기회로 전송 |
| C → S | `game:forfeit` | 기권 |
| S → C | `game:over` | 게임 종료 (승 / 패 / 무, 레이팅 변화) |
| S → C | `session:replaced` | 다른 접속으로 대체되어 로그아웃됨 |

## 계약 확정 전 확인할 항목

- 인증 전달·실패 응답·권한 검사 위치: [인증 설계](AUTH.md)
- 요청·응답·오류 스키마, 이벤트 순서, 재전송·중복 요청 처리
- 발사·증강 요청과 턴 변경의 경합, 시간초과와 입력의 우선순위
- 플레이어별 공개·비공개 필드, 로비 구독·해제와 방 만료
- 호환성·버전 변경, 속도 제한의 단위와 실패 형식

기존 이벤트명은 미정이다. 후보 표에 있는 30초 등의 제품 값은 [게임 규칙](../PRD.md#게임-규칙)을 참조하며 여기서 새로 결정하지 않는다.
