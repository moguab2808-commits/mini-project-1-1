# 변경 이력

사용자에게 의미 있는 기능·동작·정책 변경을 날짜별로 요약한다. 다른 정보의 위치는 [AGENTS](../AGENTS.md#작업-목적에-따라-읽을-문서)를 따른다.

출시·배포된 변경과 계획을 구분하고, 작업 체크리스트·명령 출력·후보안을 출시 변경으로 기록하지 않는다.

## 미출시

- 바 테마의 게임 장면을 로그인 일러스트 화풍의 "장난감 왕국" 원목 놀이방으로 바꿨다. 장난감 선반·꼬마전구·깃발·초저녁 창·마법 반짝이, 놋쇠 펜던트 조명, 둥근 꿀색 책상과 금테 판이다. 규칙·조작은 그대로다([DEC-079](DECISIONS.md#결정-색인), [IMPL-025](TASKS.md#impl-025-인게임-테마-화풍바-테마-예시)). 병합 전.
- 방해요소 전체와 HUD 방해요소 아이콘을 같은 화풍으로 바꿨다: 해골 폭탄, 보라 소용돌이 블랙홀 자석, 별빛 우물 구멍, 초록 슬라임 끈끈이, 주황 장난감 벽돌 벽, 장난감 물총과 파란 물줄기, 파란 마법 중력 구역, 반질반질한 얼음판, 분홍 마법진 방향 반전, 보랏빛 분신술 허상, 금빛 손전등 빛, 금빛 기절 별. 진한 색과 광택을 썼고 판정·동작은 그대로다([DEC-080·DEC-081](DECISIONS.md#결정-색인), [IMPL-026](TASKS.md#impl-026-방해요소-화풍)). 병합 전.
- 자석에 빨려 든 알은 개수와 상관없이 2초 동안 중심을 돌다가 중심(차 있으면 바로 옆)에 멈춘다. 여러 알이 중심에서 부딪혀 계속 돌거나 튕겨 나가던 문제가 없어졌다. 도는 동안 턴이 끝나지 않는다([DEC-082](DECISIONS.md#결정-색인), [IMPL-027](TASKS.md#impl-027-자석-궤도-정지)). 병합 전.
- 나머지 세 테마도 같은 화풍으로 바꿨다: 밤 옥상은 장난감 성의 별빛 옥상, 교실은 마법학교 교실, 해변은 장난감 해적섬의 노을 해변이다. 테마 이름은 그대로다([DEC-083](DECISIONS.md#결정-색인), [IMPL-028](TASKS.md#impl-028-나머지-테마-3종-화풍)). 병합 전.
- 소리를 넣었다: 로비와 테마별 배경음악(오르골·실로폰 풍), 테마별 배경 소리(파도·풀벌레·새소리 등), 발사·알 부딪힘·떨어짐·방해요소별·턴·남은 시간·결과·감정표현·버튼 효과음. 환경설정에서 배경음악·배경 소리·효과음 음량을 따로 조절한다. 배경음악·테마 배경 소리·알 소리·감정표현 목소리는 고른 CC0 녹음이고 나머지는 코드로 합성했다. 판 밖으로 떨어질 때는 소리가 없다([DEC-084·DEC-086](DECISIONS.md#결정-색인), [IMPL-029](TASKS.md#impl-029-소리배경음악배경-소리효과음)). 병합 전.
- 로그인·경기·AI 설정 화면 오른쪽 위에 소리 버튼을 더했다. 눌러서 소리를 켜고(브라우저는 첫 클릭 전에는 소리를 막는다) 경기 중에도 배경음악·배경 소리·효과음을 켜고 끄거나 음량을 바꾼다([DEC-087](DECISIONS.md#결정-색인)). 병합 전.

#### 2026-11-04

- 게임 속 캐릭터의 손을 손가락 다섯 개로 바꿨다. 조준 중에는 손등을 오른쪽으로 세워 굽힌 중지를 엄지에 걸고, 칠 때 중지를 앞으로 튕겨 편다. 상대 캐릭터도 같다([DEC-077](DECISIONS.md#결정-색인), [IMPL-023](TASKS.md#impl-023-게임-캐릭터-손-다섯-손가락)).
- 캐릭터 꾸미기 창의 3D 미리보기를 방 생성 창과 같은 전신으로 바꿨다. 왼쪽 버튼으로 끌어서 좌우로 돌려 볼 수 있다([DEC-076](DECISIONS.md#결정-색인), [IMPL-022](TASKS.md#impl-022-캐릭터-꾸미기-창-3d-미리보기-화풍)).
- 화면 디자인을 새 기준(L 한밤의 마법 알까기)으로 바꿨다. 로그인·회원등록(일러스트 배경), 로비(오른쪽 위 프로필 명판, 방 테마별 지역 4열 방 목록), 방 생성 창(내 캐릭터 3D 전신), 대기실(블러 배경), 캐릭터 꾸미기·환경설정·코드 입력·규칙 창, 토스트가 같은 화풍이다. 게임 이름은 "증강 알까기"로 표시한다([DEC-069~074](DECISIONS.md#결정-색인), [IMPL-019](TASKS.md#impl-019-l-화풍-화면-적용)).
- 자석을 블랙홀처럼 바꿨다. 범위에 닿은 움직이는 알·떠 있는 알은 휘어 지나가지 않고 자석 중심으로 빨려 들어가 멈춘다([DEC-068](DECISIONS.md#결정-색인)).
