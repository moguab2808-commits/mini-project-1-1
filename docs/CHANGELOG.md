# 변경 이력

사용자에게 의미 있는 기능·동작·정책 변경을 날짜별로 요약한다. 다른 정보의 위치는 [AGENTS](../AGENTS.md#작업-목적에-따라-읽을-문서)를 따른다.

출시·배포된 변경과 계획을 구분하고, 작업 체크리스트·명령 출력·후보안을 출시 변경으로 기록하지 않는다.

## 미출시

### 2026-11-04 (작업 브랜치)

- 자석을 블랙홀처럼 바꿨다. 범위에 닿은 움직이는 알·떠 있는 알은 휘어 지나가지 않고 자석 중심으로 빨려 들어가 멈춘다([DEC-068](DECISIONS.md#결정-색인)).

### 2026-11-03 (작업 브랜치)

- AI·로컬 2인 경기에 숫자키 1~6·메뉴로 쓰는 감정표현 6종을 추가했다. 몸짓·말풍선·효과음과 3초 입력 제한을 적용하고 조준 중 팔 조작은 유지한다. 온라인 연결은 후속이다([IMPL-017](TASKS.md#impl-017-감정표현-구현)).
- 가짜벽은 지정 위치에 진짜 벽 1개, 빈 무작위 위치에 가짜 2개가 동시에 생기도록 변경했다. 알·설치물과 겹치면 배치하지 않는다([DEC-066](DECISIONS.md#결정-색인)).
- 방해요소 교체를 발사 턴마다에서 라운드마다(두 사람이 한 번씩 쏜 뒤)로 바꿨다. 자석·중력 구역 힘을 3배로 올리고 떠서 가는 알에도 적용하며, 설치형 지속을 5초씩 늘렸다(15초, 미끄럼 장판 13초)([DEC-067](DECISIONS.md#결정-색인)).
- 서버 없는 AI·로컬 2인 실행·조작 안내를 README에 보완했다([DOC-011](TASKS.md#doc-011-readme-설치실행-절차)).

검증 조건·한계는 [worklog](worklogs/2026-11-03.md#impl-015016017018-로컬ai-마무리)를 따른다. 아직 배포하지 않았다.
