# 변경 이력

사용자에게 의미 있는 기능·동작·정책 변경을 날짜별로 요약한다. 다른 정보의 위치는 [AGENTS](../AGENTS.md#작업-목적에-따라-읽을-문서)를 따른다.

출시·배포된 변경과 계획을 구분하고, 작업 체크리스트·명령 출력·후보안을 출시 변경으로 기록하지 않는다.

## 미출시

- 캐릭터 꾸미기에 안경(선글라스 포함)·모자·옷 3개 항목을 더했다. 항목마다 5가지이고 모자를 쓰면 짧은·뾰족 머리는 가려지며 단발·긴 머리는 옆·뒤 머리만 보인다([DEC-078](DECISIONS.md#결정-색인), [IMPL-024](TASKS.md#impl-024-아바타-꾸미기-항목-확장안경모자옷)). 실제 DB·온라인 확인은 남아 있다.
- 배포(`ddc5337`) 이후 위 외의 사용자 변경은 아직 없다.

## 출시

- Render 무료 웹 서비스에 `main`(PR #95 병합까지)을 수동 배포했다(첫 배포는 2026-11-03 `e97b81a`). 아래 날짜별 항목은 이 배포 시점까지 `main`에 반영된 변경이다. 배포 확인과 남은 일(롤백·로그 보관·해시 시간 조정)은 [worklog](worklogs/2026-11-04.md#impl-013-운영-배포-확인)와 [IMPL-013](TASKS.md#impl-013-배포)에 있다.

#### 2026-11-04

- 게임 속 캐릭터의 손을 손가락 다섯 개로 바꿨다. 조준 중에는 손등을 오른쪽으로 세워 굽힌 중지를 엄지에 걸고, 칠 때 중지를 앞으로 튕겨 편다. 상대 캐릭터도 같다([DEC-077](DECISIONS.md#결정-색인), [IMPL-023](TASKS.md#impl-023-게임-캐릭터-손-다섯-손가락)).
- 캐릭터 꾸미기 창의 3D 미리보기를 방 생성 창과 같은 전신으로 바꿨다. 왼쪽 버튼으로 끌어서 좌우로 돌려 볼 수 있다([DEC-076](DECISIONS.md#결정-색인), [IMPL-022](TASKS.md#impl-022-캐릭터-꾸미기-창-3d-미리보기-화풍)).
- 화면 디자인을 새 기준(L 한밤의 마법 알까기)으로 바꿨다. 로그인·회원등록(일러스트 배경), 로비(오른쪽 위 프로필 명판, 방 테마별 지역 4열 방 목록), 방 생성 창(내 캐릭터 3D 전신), 대기실(블러 배경), 캐릭터 꾸미기·환경설정·코드 입력·규칙 창, 토스트가 같은 화풍이다. 게임 이름은 "증강 알까기"로 표시한다([DEC-069~074](DECISIONS.md#결정-색인), [IMPL-019](TASKS.md#impl-019-l-화풍-화면-적용)).
- 자석을 블랙홀처럼 바꿨다. 범위에 닿은 움직이는 알·떠 있는 알은 휘어 지나가지 않고 자석 중심으로 빨려 들어가 멈춘다([DEC-068](DECISIONS.md#결정-색인)).
