# 제품 요구사항 요약

근거는 기존 [제안서 원문](../PRD.md)이다. 이 문서는 범위 안내이며 상세 규칙을 복제하지 않는다. 원문에서 개별 항목에 붙인 초안·후보·미확정 표시와 14장의 미완료 항목은 미정으로 취급한다. 본문과 이 표시가 충돌하면 합의 전까지 미정으로 유지한다. 문서 전체의 초안 상태와 개별 항목의 명시적 확정은 구분한다.

요구사항의 합의된 변경은 원문 해당 절·관련 14장 항목과 [결정 기록](DECISIONS.md)을 같은 PR에서 갱신한다. 이 요약에는 달라진 범위와 참조만 반영한다.

## 제안서에 명시된 내용

| 구분 | 내용 | 원문 위치 |
| --- | --- | --- |
| 배경·문제 | 증강 윷놀이에서 영감을 받아 알까기에 증강을 적용한다. 별도의 사용자 불편·시장 문제 정의는 명시되지 않아 미정이다. | [1.2절](../PRD.md) |
| 목표 | 서로 다른 PC의 웹 링크 접속으로 대전하고, 증강 선택의 전략적 재미를 검증하며, 회원·전적·랭킹을 영구 저장하고 무료로 온라인 배포한다. | [1.2~1.3절, 12장](../PRD.md) |
| 대상 사용자 | 개발자 본인과 지인, 데스크톱 PC의 최신 Chrome·Edge 사용자 | [2장](../PRD.md) |
| 주요 기능 | 턴제 알까기, 증강 선택·보유·사용, 판 선택, 방 생성·참여·대기실, 회원·프로필, 전적·Elo 랭킹, 건의, 음량 설정 | [3~4장, 6장](../PRD.md) |
| MVP 범위 | 1:1 온라인 대전과 위 기능. 증강별 초안·세부 규칙과 단계별 필수·선택 범위는 원문에서 구분한다. | [3.6절, 11장](../PRD.md) |
| 제외 범위 | 상업적 출시·결제·광고, 모바일 최적화, 다인 대전·관전·리플레이, 재접속 복구, AI 봇, 소셜 로그인·이메일 인증·비밀번호 찾기, 건의 첨부 파일, 배경음악 | [1.4절, 5.5절](../PRD.md) |

## 미정 사항

- 게임 규칙·증강 효과와 밸런스·선택 주기·화면 세부 중 미완료 항목: [원문 14.1·14.5절](../PRD.md). 본문에 설명이 있어도 미완료 항목을 확정으로 바꾸지 않는다.
- 기술·설계의 확정 근거와 미정 항목: [DESIGN.md](DESIGN.md). 원문 5.0절의 후보를 이후 절에서 사용한 경우도 채택으로 간주하지 않는다.
- 원문 상단 버전은 v0.1, 변경 내역은 v0.6까지 있어 기준 버전 표기는 확인이 필요하다. 담당자와 개발 일정은 미정이다.
