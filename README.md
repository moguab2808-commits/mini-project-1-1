# 증강 알까기 (Augmented Alkkagi)

알까기에 증강 시스템을 더한 데스크톱 웹 브라우저용 1:1 온라인 대전 미니프로젝트다.

## 문서 안내

- [요구사항 요약](docs/PRD.md)과 [기존 제안서 원문](PRD.md)
- [협업 흐름](docs/CONTRIBUTING.md), [작업 관리](docs/TASKS.md), [구현 현황](docs/PROGRESS.md)
- 전체 문서의 위치·역할과 작업별 읽기 순서: [AGENTS.md](AGENTS.md)

## 실행

이 저장소에는 아직 구현 코드와 실행 설정이 없다. 설치·실행·테스트 명령은 미정이다. 실제 구성이 추가되고 검증되면 이 절을 실행 안내의 진입점으로 갱신한다.
